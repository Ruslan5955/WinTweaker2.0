# WinTweaker 3.0

Твикер настроек Windows 10/11 со встроенным антивирусным сканером. Python + customtkinter.
Все твики обратимы: выключили переключатель, значение вернулось.

## Твики (87)
Интерфейс, Приватность, Производительность, Система, Защита, Сеть, Службы.
Поиск по настройкам, «Рекомендуемые», «Сбросить всё», экспорт и импорт профиля (JSON).

## Система
- Менеджер автозагрузки (включить/отключить без удаления, подозрительное помечается ⚠)
- Удаление встроенных приложений
- Инструменты: очистка Temp и корзины, DNS, планы питания, SFC/DISM, точка восстановления,
  SMART дисков, сброс кэша обновлений, оптимизация TCP, отключение SMBv1 и PowerShell 2.0, GodMode
- Быстрый доступ к скрытым окнам настроек, сведения о системе

## Антивирус (guard.py)
- Сканер: быстрая, полная проверка и проверка папки
- Постоянный мониторинг новых файлов в Загрузках, на рабочем столе и в Temp
- Эвристика: исполняемые под видом .jpg/.pdf, двойные расширения, подделка под системные файлы,
  упаковка (энтропия), опасные скрипты (PowerShell -enc, удаление теневых копий и др.), вредные ярлыки
- Карантин (восстановить / удалить), проверка хэша на VirusTotal (свой API-ключ)
- Аудит процессов, сетевых соединений, автозагрузки и файла hosts
- Управление Защитником Windows (обновление баз, проверки, облачная защита, PUA, защита папок от шифровальщиков)
- Импорт своих списков хэшей (SHA-256), тест EICAR

**Важно:** это второй слой защиты. Нет драйвера уровня ядра, облачной базы и блокировки по поведению,
поэтому Защитник Windows держите включённым.

## Запуск
    pip install -r requirements.txt
    python tweaker.py

Для пунктов с пометкой «админ» запускайте от имени администратора.

## Сборка .exe
Запушьте в GitHub: Actions -> Build exe -> Artifacts -> WinTweaker-exe.
Локально:
    pyinstaller --onefile --noconsole --uac-admin --collect-all customtkinter --name WinTweaker tweaker.py

## Свой твик
Допишите `Tweak(...)` в список `TWEAKS` в tweaker.py.
